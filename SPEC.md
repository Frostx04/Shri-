ТЗ для Claude Code. Положи эту папку в корень нового репозитория и скажи:
«Прочитай SPEC.md, data/seed.json и source/plan.txt. Сделай проект по ТЗ, по этапам из раздела 12. После каждого этапа — коммит.»

---

## 1. Что делаем

Мобильное веб-приложение (PWA) для поездки вдвоём (Никита и Дара) в Мириссу, Шри-Ланка, **13–24 марта 2027**. Это не просто гид, а:

1. **Адвент-календарь**: 12 «дверок» — по одной на каждый день поездки. До поездки — обратный отсчёт; дверка открывается в свой день (можно подсмотреть заранее, но с анимацией «подглядывания»).
2. **План дня с картой**: время → место → как едем → что делаем → где едим → сколько стоит. Маршрут дня рисуется линией на карте с номерами точек.
3. **Каталог мест**: карточки с фото, рейтингом «топ / хорошо / по желанию», подробным «как добраться», чем заняться, ценой, что взять, подводными камнями, контактами и готовым сообщением в WhatsApp.
4. **Отметки «были / не были»**: галочка, своя оценка (1–5 звёзд), заметка, свои фото. Видно прогресс поездки.
5. **Бюджет**: план и факт по статьям, в рупиях и долларах.
6. **Чек-лист бронирований**: кому и когда писать («за 3 недели — Ачи, Синхараджа»), отметка «написали / подтвердили».
7. Работает **офлайн** (на острове слабый интернет): данные, фото и карта района Мириссы кешируются.

Язык интерфейса — русский. Пользуются с телефонов (iPhone и Android), 2 человека.

## 2. Стек (рекомендация, можно предложить лучше)

- **Vite + React + TypeScript**, Tailwind CSS.
- **Карта**: Leaflet + react-leaflet, тайлы OpenStreetMap (с атрибуцией). Кеширование тайлов района (bbox Матара–Галле–Удавалаве, зумы 9–16) через service worker.
- **Маршруты**: считаются **заранее при сборке** скриптом `scripts/build-routes.ts` через OSRM (`router.project-osrm.org`, профиль driving), результат — GeoJSON в `public/routes/day-XX.json`. В рантайме ничего не запрашиваем → работает офлайн. Если OSRM недоступен — рисуем прямые пунктирные линии.
- **PWA**: vite-plugin-pwa, иконка, установка на домашний экран.
- **Хранилище**: прогресс (галочки, оценки, заметки, фото, траты) — IndexedDB (через `idb-keyval` или Dexie). Свои фото сжимать до ~1600px JPEG.
- **Синхронизация между двумя телефонами** (этап 2, по флагу): Supabase (бесплатный план), без логина — общий «код поездки». Пока нет синка — экспорт/импорт прогресса в JSON-файл и через ссылку.
- **Деплой**: GitHub Pages через GitHub Actions (`.github/workflows/deploy.yml`), `base` в vite.config под имя репозитория.
- Тесты: Vitest для утилит (валюты, даты, расписание), Playwright smoke-тест на главный экран и день.

## 3. Данные

Весь контент — в JSON, чтобы правилось без кода. Стартовые данные уже собраны в `data/seed.json` (из реального плана поездки `source/plan.txt` — это первоисточник, в нём больше деталей; при расхождении верить ему).

### 3.1 Схемы (TypeScript)

```ts
type Tier = 'top' | 'good' | 'optional';        // топ / хорошо / по желанию
type Transport = 'walk' | 'tuktuk' | 'taxi_app' | 'tuktuk_wait' | 'car_day' | 'car_halfday' | 'operator_pickup' | 'transfer';

interface Place {
  id: string;                 // 'sinharaja'
  name: string;               // 'Синхараджа: тропический лес'
  nameLocal?: string;         // 'Sinharaja Forest Reserve' — для поиска в Google Maps
  category: 'beach'|'animals'|'nature'|'culture'|'food'|'spa'|'shop'|'hotel'|'airport'|'medical';
  tier: Tier;
  emoji?: string;
  coords: [number, number] | null;  // [lat, lng]
  coordsVerified: boolean;    // false → проверить (см. 3.3)
  gmapsQuery: string;         // строка для ссылки https://www.google.com/maps/search/?api=1&query=...
  why: string[];              // зачем едем (пункты)
  howToGet: string;           // подробно: от отеля, сколько ехать, где выйти
  transport: Transport;
  travelTimeMin?: number;     // от отеля, в одну сторону
  whatToDo: string[];
  whenToCome: string;
  costLkr?: [number, number]; // диапазон на двоих
  costUsd?: [number, number]; // если цена в долларах
  costNote?: string;
  bring: string[];
  pitfalls: string[];         // подводные камни — показывать жёлтой плашкой
  contacts: Contact[];
  bookAhead?: { daysBefore: number; note: string };
  messageTemplateId?: string;
  hours?: string;
  photos: Photo[];
  sources: string;            // откуда инфа (чат, дата, TripAdvisor…)
  rating?: { source: string; value: number; count?: number };
}

interface Contact { kind: 'whatsapp'|'phone'|'telegram'|'instagram'|'site'|'email'|'gmaps'; value: string; label?: string; }
interface Photo { src: string; author: string; license: string; sourceUrl: string; }

interface DayPlan {
  date: string;               // '2027-03-16'
  title: string;              // 'Синхараджа — день зверей'
  emoji: string;
  mood: 'active'|'easy'|'rest'|'travel';
  doorTeaser: string;         // текст за дверкой адвента
  backupNote?: string;        // 'Ливень → переносим на 22.03'
  steps: Step[];
}

interface Step {
  time: string;               // '05:00'
  placeId?: string;           // ссылка на Place
  title: string;              // если нет placeId или для уточнения
  kind: 'move'|'activity'|'food'|'rest'|'book';
  transport?: Transport;
  durationMin?: number;
  costLkr?: [number, number];
  costUsd?: [number, number];
  note?: string;
}

interface MessageTemplate { id: string; to: string; lang: 'en'|'ru'; text: string; }
interface BudgetLine { id: string; title: string; planUsd: [number, number]; }
```

### 3.2 Файлы
`data/places.json`, `data/days.json`, `data/templates.json`, `data/budget.json`, `data/info.json` (общие правила, безопасность, чёрный список, «куда не ехать», экстренные номера). Разнести их из `seed.json` скриптом или вручную на этапе 1.

### 3.3 Координаты
В seed координаты приблизительные, `coordsVerified: false`. Скрипт `scripts/geocode.ts` проходит по местам с `coordsVerified: false`, ищет через Nominatim (OpenStreetMap, 1 запрос/сек, свой User-Agent) по `nameLocal` + «Sri Lanka», и пишет отчёт `data/geocode-report.md`: старые/новые координаты и расстояние между ними. Автоматически не перезаписывать — я проверю и подтвержу.

### 3.4 Фото
Скрипт `scripts/fetch-photos.ts`: для каждого места ищет 2–4 фото на **Wikimedia Commons** (API, поиск по `nameLocal`, только лицензии CC0 / CC BY / CC BY-SA / Public Domain), качает в `public/photos/<placeId>/`, ресайз до 1600px webp + превью 400px, пишет автора, лицензию и ссылку в данные. Страница «Авторы фото». Без фото — красивая заглушка с эмодзи и цветом категории. Фото из Google/TripAdvisor не брать (лицензии).

## 4. Экраны

Нижняя навигация: **Календарь · Сегодня · Карта · Места · Ещё**.

### 4.1 Календарь (главный, адвент)
- Сетка 12 дверок (4×3 на телефоне), каждая — дата, день недели, эмодзи, цвет по `mood`.
- До 13.03.2027: сверху обратный отсчёт «До Шри-Ланки 120 дней 4 часа», дверки закрыты. Тап по закрытой — анимация «подглядывания» (дверка приоткрывается, видно `doorTeaser`), кнопка «Всё равно открыть».
- Наступил день — дверка «светится», открывается анимацией (CSS 3D-поворот), конфетти один раз.
- Прошедшие дни — с отметкой прогресса (3/4 места посещено ✓).
- Отдельная дверка-бонус «24 марта: домой» с итогами поездки (сколько мест, км, трат, лучшая оценка).
- Режим «до поездки» можно переключить в «как будто сегодня 16.03» (dev-переключатель даты в настройках — для проверки).

### 4.2 День (по тапу на дверку и вкладка «Сегодня»)
- Шапка: дата, название, погода-заметка (статично), бейдж «Особый день» (21.03 — Пойя: алкоголь и мясо не продают).
- **Карта сверху** (40% экрана, сворачивается): маршрут дня линией, точки пронумерованы по шагам, отель — домик. Тап по точке — скролл к шагу.
- **Таймлайн** шагов: время, иконка транспорта, название, длительность, цена. Между шагами — «🛺 тук-тук ~15 мин, ~800 ₨».
- У шага с местом — кнопки: «Карточка места», «Открыть в Google Maps» (навигация от текущей точки), «Написать» (WhatsApp с шаблоном), галочка «Были».
- Внизу: итого за день (план), поле «Сколько потратили» и заметка дня.
- Плашка `backupNote` (запасной план).

### 4.3 Карта
- Все места маркерами, цвет по категории, размер по `tier`. Отель всегда виден.
- Фильтры: категория, tier, «были / не были», «на этот день».
- Посещённые — с галочкой на маркере.
- Кнопка «Где я» (геолокация) и «Как доехать» → Google Maps.

### 4.4 Места (каталог)
- Список карточек с фото, фильтры и поиск. Сортировка: по дню в плане, по tier, по расстоянию от отеля.
- **Карточка места** (полный экран): галерея фото → бейдж tier и рейтинг → «Зачем едем» → «Как добраться» (подробно + время + тип транспорта) → «Чем заняться» → «Когда приезжать» → «Сколько стоит» (₨ и $) → «Что взять» (чек-лист с галочками) → «Подводные камни» (жёлтая плашка) → «Контакты» (кнопки WhatsApp / позвонить / Telegram / сайт) → «Готовое сообщение» (копировать / открыть WhatsApp с текстом) → «Источник».
- Блок «Мы тут были»: галочка, дата, звёзды, заметка, свои фото (из галереи/камеры).

### 4.4а Еда
Отдельная вкладка (или фильтр в «Местах»):
- **кафе списком и на карте**, фильтры: район, кухня, «мягко для желудка», чек ₨ / ₨₨ / ₨₨₨, «открыто сейчас» (по часам и дню недели);
- **карточка кафе**: фото, чек, **меню с ценами** (₨ + $), бейджи «остро / мягко», «что заказать», часы, выходные, отзывы и дата проверки;
- кнопка «Добавить блюдо и цену» — меню правится прямо с телефона: сфотографировали ценник и записали;
- блок **«Не идём»** красным: кафе с плохими свежими отзывами.

### 4.4б Вся Шри-Ланка
- Карта страны со всеми местами. Цвет — по региону, иконка — по `tripType`: полдня, день, с ночёвкой, на будущее. Мириссу и отель видно всегда.
- Список по регионам с расстоянием и временем в пути от отеля.
- Кнопки «Добавить в план на день…» и «Хочу в следующий раз» (вишлист).
- Мини-маршруты по регионам (`itineraries.json`) — как экран дня.

### 4.5 Ещё
- **Бюджет**: статьи из `budget.json` (план), факт из трат по дням + ручные траты. Прогресс-бар «$2000 наличными». Курс в настройках (по умолчанию 330 ₨ за $1).
- **Брони**: список «кому писать и когда» — дата дедлайна вычисляется из `bookAhead.daysBefore` и даты дня. Статусы: не писали → написали → подтвердили → оплачено на месте. Подсветка просроченных.
- **Правила и безопасность**: из `info.json` — океан и флаги, животные (бешенство!), денге, обезьяны, скорпионы, ETA, табак. «Куда не ехать» и «Чёрный список номеров».
- **Экстренное**: номера с кнопкой «позвонить», ближайшие больницы/аптеки на карте.
- **Сообщения**: все шаблоны.
- **Настройки**: курс, синхронизация (код поездки), экспорт/импорт, сброс, «авторы фото».

## 5. Логика и мелочи

- Ссылки WhatsApp: `https://wa.me/<номер без +>?text=<urlencoded шаблон>`. Номера в формате +94…
- Google Maps: `https://www.google.com/maps/dir/?api=1&destination=lat,lng` (если coords есть) иначе `search/?api=1&query=gmapsQuery`.
- Валюта: показывать ₨ основной, $ серым рядом. Формат `5 000 ₨ (~$15)`.
- Время — местное Шри-Ланки (UTC+5:30); учесть, что телефон может быть в ташкентском (UTC+5). «Сегодня» определять по времени Шри-Ланки.
- Даты на русском: «Вт, 16 марта».
- Прогресс: «Посетили 9 из 17 мест», кольцо на главном.
- Мелкие анимации (открытие дверки, галочка), но без тяжёлых библиотек; `prefers-reduced-motion` уважать.
- Тёмная тема по системе.

## 6. Дизайн

Тёплый «тропический» стиль, но читаемый: песочный фон, бирюзовый (океан), коралловый (акценты), зелёный (джунгли). Карточки со скруглением 16–20px. Шрифт с кириллицей (например Manrope / Inter + заголовки Yeseva One или Playfair Display). Крупный текст — читать будут на солнце. Иконки — lucide-react. Всё удобно одной рукой.

## 7. Персональные условия (важно для контента)

- Едут вдвоём, один отель на всю поездку: **Aura by Epic Collection, Yatipila Rd, Мирисса**. Без аренды байка/машины — только тук-туки, такси (PickMe/Uber) и машина с водителем на день.
- Приоритет — **животные без жестокости**: Пиннавела, катание на слонах, черепашьи фермы, фото с обезьянкой — НЕ показываем как варианты (они в «Куда не ехать»).
- У Дары **чувствительный желудок**: у еды показывать пометку «мягко для желудка» / «острое», в плане дня — проверенные места (Shady Lane, Quinta, Dewmini — не остро попросить).
- Купаться каждый день — у дней без пляжа подсказка «вечером бассейн в отеле».
- Синхараджа — обязательный пункт (есть запасной день 22.03).

## 8. Офлайн

- Service worker кеширует приложение, JSON, все фото (превью — всегда, большие — по мере открытия + кнопка «Скачать всё для офлайна» в настройках с прогрессом и размером).
- Тайлы: кнопка «Скачать карту района» (bbox + зумы), с оценкой размера. Без сети — показывать кешированное, не падать.

## 9. Синхронизация (этап 2)

- Таблица `progress` в Supabase: `trip_code, key, value jsonb, updated_at, device`. Last-write-wins по `updated_at`.
- Синкаются: галочки, оценки, заметки, траты, статусы броней. Свои фото — только локально (или Supabase Storage по флагу).
- Ключи в `.env` (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`), без них приложение работает локально. RLS: доступ только по `trip_code`.
